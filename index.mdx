## Get Up and Running

<Steps>
  <Step title="Create an Account">
    Sign up at the Developer Portal and verify your email address to activate your account.
  </Step>
  <Step title="Browse the API Catalog">
    Explore the available APIs, review their specifications, and choose the ones that fit your use case.
  </Step>
  <Step title="Subscribe to an API">
    Select a subscription plan and subscribe to the API. Your subscription unlocks access and sets your usage quota.
  </Step>
  <Step title="Generate an API Key">
    From your account dashboard, create an API key scoped to the APIs you've subscribed to.
  </Step>
  <Step title="Make Your First Request">
    Pass your API key in the `Authorization` header and start calling the API. Check the guides for working code examples.
  </Step>
</Steps>
