sidebarTitle: "Quick Start"

---

The fastest way to experience the Developer Portal is to go from zero to a live API response. This guide walks you through every step — creating your account, picking an API, generating a key, and firing off your first authenticated request. By the end, you'll have a working integration and a clear picture of how the portal fits into your development workflow.

<Steps>
  <Step title="Create an account">
    Head to [portal.example.com/signup](https://portal.example.com/signup) and register for a free account. Fill in your name, email address, and a secure password, then confirm your email address using the link sent to your inbox. Once confirmed, you'll land on your personal dashboard where your subscriptions, API keys, and usage metrics all live.
  </Step>

  <Step title="Browse and subscribe to an API">
    From your dashboard, navigate to the **API Catalog** in the left sidebar. Browse available APIs or use the search bar to find one by name or category. Click any API to view its documentation, available plans, and rate limits. When you're ready, click **Subscribe**, choose a plan that fits your expected usage, and confirm. Your new subscription will appear immediately in the **My Subscriptions** section of your dashboard.
  </Step>

  <Step title="Generate an API key">
    Go to **Account → API Keys** in the top navigation. Click **Create New Key**, give it a descriptive name (for example, `my-first-key`), and optionally scope it to specific subscribed APIs. Click **Generate** — your new key appears once. Copy it and store it somewhere safe, such as a password manager or a `.env` file. You won't be able to view the full key again after closing this dialog.
  </Step>

  <Step title="Make your first request">
    With your API key in hand, you're ready to make an authenticated request. Replace `YOUR_API_KEY` in the examples below with the key you just generated.

    <CodeGroup>
      ```bash curl
      curl https://api.example.com/v1/catalog \
        -H "Authorization: Bearer YOUR_API_KEY"
      ```

      ```javascript JavaScript
      const response = await fetch("https://api.example.com/v1/catalog", {
        method: "GET",
        headers: {
          "Authorization": "Bearer YOUR_API_KEY",
          "Content-Type": "application/json",
        },
      });

      const data = await response.json();
      console.log(data);
      ```
    </CodeGroup>

    A successful response returns a `200 OK` status and a JSON body containing the catalog data. If you receive a `401 Unauthorized` error, double-check that you've copied the full key and that it is prefixed with `Bearer `.
  </Step>

  <Step title="Check your usage in the dashboard">
    After making a request, go to **Account → Usage** in the dashboard. You'll see your call count update in real time, along with a breakdown by API, endpoint, and time period. Use this view to monitor quota consumption, identify spikes, and plan upgrades before you hit a rate limit.
  </Step>
</Steps>

<Tip>
  Ready to explore all available endpoints, request parameters, and response schemas? Head over to the [API Reference](/api-reference) for the full interactive documentation.
</Tip>
